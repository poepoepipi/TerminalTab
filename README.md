# TerminalTab

## introduction
TerminalTab is a free and open-source project that lets you search the internet, manage bookmarks, and more, all from a terminal-like interface in your browser. It provides a unique browsing experience for people who enjoy using command-line interfaces.


## How To Set Up
Setting TerminalTab as your new-tab page differs between browsers. Below are instructions for some common browsers. If your browser isn't listed, you can probably find instructions online for setting a custom new-tab page.

### Firefox-based browsers
Firefox does not natively support setting a custom website as the new-tab page, so you'll need an extension such as New Tab Override.

1. Install New Tab Override from the Firefox Add-ons website.
2. Open the extension's settings.
3. Enter the TerminalTab URL as your new-tab page.
4. Open a new tab to verify that TerminalTab is working.

### Chrome-based browsers
Chrome does not natively allow you to replace the new-tab page with a custom URL, so you'll need an extension such as Custom New Tab.

1. Install a new-tab extension from the Chrome Web Store.
2. Open the extension's settings.
3. Enter the TerminalTab URL.
4. Open a new tab to verify that TerminalTab is working.
